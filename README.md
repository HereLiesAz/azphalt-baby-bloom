# Baby Bloom

A soft pink beauty bloom — brightened skin tones, warm rosy highlights, and gently reduced contrast for that clean pastel look.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.baby-bloom`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `stylize`, `beauty`, `pink`, `pastel`, `soft`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `bloom` | Bloom | 0.0 – 1.0 | 0.5 |
| `pink` | Pink tint | 0.0 – 1.0 | 0.45 |

## Install

Open **Azphalt Store** inside Guillotine, find *Baby Bloom*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
